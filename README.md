# Hermes Website Prototype

Minimal editorial/path-first Astro prototype for `hermeslogisticus.com`.

## Status

- Local prototype only.
- No production publishing or DNS changes.
- No form submission or data storage.
- No unsupported numeric claims or partner logos.

## Structure

- `src/data/site.ts`: structured content and claim register.
- `src/components`: reusable homepage sections.
- `src/styles/global.css`: design tokens and responsive system.
- `src/pages/index.astro`: homepage composition.

## Commands

```bash
npm install
npm run dev
npm run build
npm test
```
