# Hermes Connect Web App

Hermes Connect is a web-first product for service businesses to present services, request windows, and a clear client request path.

## Current public capability

- Choose a service-business category.
- Review an example service/request workflow.
- Submit a request for controlled Web App access.
- Learn how Hermes uses an AI-assisted build and human-review release process.

## Current boundary

This public Web App does **not** automatically create an account, booking, payment, calendar event, subscription, or guaranteed service outcome. Access requests remain subject to human review and the existing Hermes delivery rules.

Private customer, candidate, carrier, employee, payment, shipment, and account data are not part of this public representation.
