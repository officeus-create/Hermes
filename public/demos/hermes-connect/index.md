# Hermes Connect Web App

Hermes Connect is a web-first operating layer with live decision tools and controlled service-business request workflows.

## Live tools

- **Load Analyzer** — compare loaded miles, deadhead, gross pay, operating assumptions, break-even, and estimated contribution using user-entered values only: https://connect.hermeslogisticsus.com/load-analyzer/
- **Search Opportunity Radar** — classify sanitized aggregate search evidence into explainable ownership, CTR, position, mismatch, and content-gap actions: https://connect.hermeslogisticsus.com/search-opportunity-radar/
- **SEO → Lead → Revenue Dashboard** — keep search, delivery, qualification, opportunity, win/loss, and revenue evidence classes separate; missing evidence remains `DATA_PENDING`: https://connect.hermeslogisticsus.com/revenue-dashboard/
- **Multi-Car Transport Planner** — prepare multi-vehicle transport information, identify coordination/readiness gaps, and hand off to the approved transport request workflow: https://connect.hermeslogisticsus.com/multi-car-planner/
- **Logistics SEO Analyzer** — turn explicit website/search facts into prioritized `P0 | P1 | P2 | MEASURE | HOLD` actions without pretending to crawl an arbitrary website or guaranteeing rankings: https://connect.hermeslogisticsus.com/logistics-seo-analyzer/

All five tool routes are intentionally `noindex,nofollow`; indexed Hermes pages remain the public search-intent owners.

## Current boundaries

Live tools do not guarantee carrier capacity, rates, profit, rankings, traffic, leads, revenue, bookings, or other outcomes. They distinguish entered facts, verified evidence, estimates, and missing data rather than inventing unavailable evidence.

The access-request workflow does **not** automatically create an account, booking, payment, calendar event, subscription, or guaranteed service outcome. Access requests remain subject to human review and the existing Hermes delivery rules.

Private customer, candidate, carrier, employee, payment, shipment, credential, and account data are not part of this public representation.
