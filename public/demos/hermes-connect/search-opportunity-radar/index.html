Review-first MVP

It drafts decisions. It does not manufacture pages.

  • No GSC credentials or property IDs are needed.
  • Query/page rows stay in the browser.
  • No query text or uploaded row is sent to analytics.
  • No page, title, link, or deployment is changed automatically.

Sanitized GSC evidence → action queue

Prioritize the pages Google is already testing before creating another URL.

This first release uses a deliberately small approved ownership map and visible thresholds. Anything outside the map is held for manual review instead of being treated as permission to generate content.

Paste sanitized aggregate CSV

One row per query/page observation. No credentials, account IDs, user data, leads, carrier/customer records, routes, rates, or private messages.

Browser only

Required: query, page, clicks, impressions, ctr, position. Optional: date_range, country_bucket, device_bucket. Private or unsupported columns are rejected rather than silently ignored.

Visible first-release decision rules

Known query, wrong pageINTENT_MISMATCH + INTERNAL_LINK_GAP. Review attribution and ownership before content changes.
Position ≤10, ≥5 impressions, CTR <2%CTR_PROBLEM + KEEP_OWNER. Review title/snippet and buyer clarity.
Position ≤30 or meaningful commercial impressionsPOSITION_OPPORTUNITY + KEEP_OWNER. Strengthen the existing owner before expanding.
Known unsupported intentINTENT_MISMATCH + NEW_PAGE_NOT_JUSTIFIED. Visibility does not authorize an invented service.
No approved mappingLOW_PRIORITY/manual review. Never auto-create a page from an unknown query.

Privacy boundary: this tool intentionally rejects columns such as email, phone, company, MC/USDOT, VIN, route, rate, token, cookie, account/property/stream IDs, and user IDs.
