# Audience Meaning Matrix — 10 Commercial Segments

Reviewed: 2026-08-04  
Purpose: internal page, CTA, FAQ, sales-script and content planning.  
Boundary: this document describes audience hypotheses and current verified Hermes capabilities. It does not authorize outcome guarantees, invented proof or automatic publication.

## Status vocabulary

- `VERIFIED_PUBLIC` — supported by current Hermes public copy or workflow.
- `OWNER_APPROVED_PENDING_SOURCE` — working audience or positioning hypothesis; confirm before publication as fact.
- `OWNER_INPUT_REQUIRED` — a real process, price, person, policy or proof is required.

## 1. Owner-operator

**Primary job:** keep the truck operating while protecting rate, time, lane position and cash flow.

| Dimension | Meaning |
| --- | --- |
| Wants | More useful loaded miles, less downtime, less broker/paperwork burden and a predictable communication routine. |
| Fears | Forced loads, weak rates, poor brokers, unpaid detention, loss of control and a dispatcher optimizing for commission rather than the carrier. |
| Typical objections | “I can dispatch myself.” “How do I know you chose the right load?” “Will you book without asking?” “What percentage do you take?” |
| Proof expected | Carrier approval language, clear service scope, actual agreement terms, equipment/lane intake, broker and document workflow. |
| Words that resonate | control, approval, lane fit, operating needs, clear communication, defined scope. |
| Words to avoid | guaranteed gross, best load, highest rate, automatic booking, passive income. |
| Primary CTA | `Review my dispatch setup` |
| Best route | `/logistics/start-car-hauling-dispatch/` or the relevant carrier intake. |
| Current status | Core control and qualification meanings are `VERIFIED_PUBLIC`; profit outcome remains blocked. |

## 2. Small fleet owner

**Primary job:** create one repeatable operating standard across several trucks without personally managing every call.

| Dimension | Meaning |
| --- | --- |
| Wants | Consistent dispatch routines, visibility across trucks, escalation rules, document order and less dependence on one employee. |
| Fears | Uneven dispatcher quality, missing updates, undocumented decisions, staff turnover and growth creating more chaos than revenue. |
| Typical objections | “Who supervises the dispatchers?” “Can the same standard work across all trucks?” “How will I see performance?” |
| Proof expected | SOP, responsibility map, reporting example, backup ownership, per-truck preferences and document controls. |
| Words that resonate | repeatable process, fleet-level visibility, ownership, escalation, operating standard. |
| Words to avoid | fully autonomous fleet, guaranteed utilization, unlimited capacity. |
| Primary CTA | `Audit my fleet dispatch workflow` |
| Best route | Logistics path plus direct carrier intake with fleet size and equipment fields. |
| Current status | Workflow scope is partly `VERIFIED_PUBLIC`; dashboards and fleet analytics require evidence. |

## 3. Growing carrier

| Dimension | Meaning |
| --- | --- |

| Fears | Bad data, duplicate records, compliance errors, unclear sources and inability to scale beyond the founder. |
| Typical objections | “I need a system, not another vendor.” “Can this connect to what we already use?” “Who owns the data?” |
| Proof expected | Source/date fields, documented workflows, modular scope, privacy boundaries, integration plan and rollback. |
| Words that resonate | operating system, data quality, source, update date, modular, controlled rollout. |
| Words to avoid | instant transformation, complete AI carrier intelligence, finished Hermes Connect platform. |
| Primary CTA | `Plan a scalable carrier operations workflow` |
| Best route | Logistics plus IT Development discovery. |
| Current status | Cross-functional capability is `VERIFIED_PUBLIC`; full product/platform claims remain internal. |

## 4. Independent car dealer

**Primary job:** move purchased vehicles into sellable inventory without avoidable storage, release or communication delays.

| Dimension | Meaning |
| --- | --- |
| Wants | Clear intake, pickup readiness, equipment fit, status communication and one accountable coordination path. |
| Fears | Storage fees, a vehicle sitting uncollected, price changes, inoperable surprises, release problems and unanswered calls. |
| Typical objections | “Why not post it myself?” “When will it actually be picked up?” “Will the quote change?” “Who handles the auction?” |
| Proof expected | Release checklist, operability fields, storage deadline, separate confirmation boundary, phone/email fallback. |
| Words that resonate | inventory readiness, auction release, condition, equipment fit, storage deadline, separate confirmation. |
| Words to avoid | guaranteed pickup, instant carrier, fixed final price, real-time tracking unless verified. |
| Primary CTA | `Request a dealer transport review` |
| Best route | `/logistics/request-vehicle-transport/?role=dealer` |
| Current status | Intake and qualification are `VERIFIED_PUBLIC`; timing, claims and capacity outcomes require confirmation. |

| Words that resonate | recurring program, consolidated workflow, priority, exception, account coordination. |
| Words to avoid | enterprise platform, unlimited nationwide capacity, API integration live unless proven. |
| Primary CTA | `Review our monthly vehicle volume` |
| Best route | Vehicle transport intake with recurring-program selection. |
| Current status | Recurring qualification is `VERIFIED_PUBLIC`; reporting/API claims are hypotheses. |

## 6. Auction buyer / reseller

**Primary job:** collect a released vehicle before storage or access problems increase cost and delay.

| Dimension | Meaning |
| --- | --- |
| Wants | Release readiness, facility context, condition/equipment review and deadline-aware coordination. |
| Fears | Missing keys or gate pass, incorrect operability, inoperable loading problems and storage accumulation. |
| Typical objections | “Do you understand Copart/IAA/Manheim procedures?” “What if it does not roll?” “What information is safe to submit?” |
| Proof expected | Non-affiliation wording, auction-source fields, release status, condition options, sensitive-data exclusion. |
| Words that resonate | released and ready, operability, winch, storage deadline, facility access, non-sensitive details. |
| Words to avoid | auction partner, guaranteed release, guaranteed deadline outcome. |
| Primary CTA | `Plan my auction pickup` |
| Best route | `/logistics/request-vehicle-transport/?role=dealer&request=auction_pickup` |
| Current status | Public intake is `VERIFIED_PUBLIC`; facility-specific operational promises require evidence. |

| Dimension | Meaning |

| Fears | No-show capacity, inaccurate updates, missing documents, cargo mismatch and unclear responsibility. |
| Typical objections | “How are carriers reviewed?” “Who updates us?” “What happens when the plan changes?” |
| Proof expected | Qualification fields, authority/insurance boundary, documented routing, fallback contact and no-guarantee wording. |
| Words that resonate | requirements, carrier review, equipment fit, documented updates, escalation. |
| Words to avoid | guaranteed capacity, guaranteed pickup, fully vetted network without current criteria. |
| Primary CTA | `Discuss recurring shipment capacity` |

| Primary CTA | `Identify one workflow worth automating first` |

| Current status | Problem-first IT scope and human review are `VERIFIED_PUBLIC`; productized platform features require proof. |

# Cross-segment page rules

1. Lead with the buyer's operational job, not the Hermes organization chart.
2. Answer control, responsibility, process and downside before the final CTA.
3. Use qualification CTAs instead of implying instant acceptance or booking.
4. Preserve direct phone/email fallback on revenue pages.
5. Do not send submitted names, phones, emails, MC/USDOT, VINs, routes or messages to analytics.
6. Separate public verified copy from internal hypotheses in data and documentation.
7. Review the matrix whenever commercial terms, curriculum, staffing or production capabilities change.
