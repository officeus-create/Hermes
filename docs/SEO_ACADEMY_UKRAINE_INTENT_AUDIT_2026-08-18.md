# Hermes SEO — Academy Ukraine Intent Audit

Date: 2026-08-18  
Current canonical program: `/academy/us-logistics-operations/`  
Status: `KEEP_PROGRAM_OWNER / UKRAINIAN_ACQUISITION_GAP_RESEARCH`

## Current search meaning

A sampled Ukrainian-language query for learning U.S. logistics surfaces dedicated commercial course pages aimed at people who want to learn dispatch/logistics work in the U.S. transportation market. These results expose course framing, curriculum, format/price or participation context and direct application/contact actions.

This is sufficient to classify the intent as real enough for continued research. It is not sufficient to establish volume, rankability or ROI.

## Current Hermes program fit

Hermes already has a substantive canonical Course owner:

`/academy/us-logistics-operations/`

The program content already covers:

- dispatch foundations;
- carrier and broker communication;
- documents/load lifecycle;
- equipment and lane logic;
- negotiation practice;
- operating routines;
- readiness/application;
- no employment or income guarantee.

The current audience explicitly includes Ukrainian- and Russian-speaking international learners who can communicate in English.

Decision: **do not create a second generic U.S. Logistics Operations course.**

## Gap

The canonical program is currently English-first. That leaves a potential acquisition gap for Ukrainian-language searchers whose query and first-screen expectations are Ukrainian.

The next question is localization ownership, not curriculum duplication.

Possible future owner patterns to research:

1. localized canonical route for the same program under the existing language architecture;
2. Ukrainian acquisition page that explains eligibility, schedule/time-zone, participation model and application context while linking to one canonical program;
3. no separate page if the existing localization system can satisfy both search and conversion intent without duplicate ownership.

No route pattern is approved by this audit.

## Diaspora country test

Sampled Ukrainian-language queries that added Germany, Poland or Czechia did **not** reveal a strong country-specific U.S.-dispatch-course SERP archetype. Results continued to surface general Ukrainian/Russian-language U.S. dispatch training and broader logistics education rather than clearly localized country acquisition pages.

This means the current evidence supports **Ukrainian-language intent first**, not immediate country-page multiplication.

### Decision

- Ukraine/Ukrainian-language acquisition: `PRIORITY_RESEARCH`.
- Germany: `DISTRIBUTION_AUDIENCE / COUNTRY_PAGE_HOLD`.
- Poland: `DISTRIBUTION_AUDIENCE / COUNTRY_PAGE_HOLD`.
- Czechia: `DISTRIBUTION_AUDIENCE / COUNTRY_PAGE_HOLD`.
- Spain: `DISTRIBUTION_AUDIENCE / COUNTRY_PAGE_HOLD` until equivalent search differentiation is observed.

Diaspora size remains useful for outreach, paid/social distribution, scheduling and language planning even when it does not justify a dedicated organic-search URL.

## What a Ukrainian acquisition surface must add

A useful page cannot be an English page translated word-for-word. It should add truthful market/audience value such as:

- Ukrainian first-screen framing;
- who the program is for in Ukraine or diaspora context;
- English readiness expectations;
- U.S. time-zone/schedule implications when approved;
- program/application status;
- participation model and boundaries;
- clear Ukrainian CTA into the application flow;
- no employment/income guarantee.

## Funnel / visual requirement

The current Academy structure is already substantial. If localization uses the same component/layout and only changes approved language/content, preserve the existing Design OS.

If the Ukrainian acquisition strategy requires a new hero, cards, pricing/status module, schedule panel, testimonials, imagery or a materially different CTA hierarchy, build a clickable preview and complete desktop + 390px QA before CEO approval and merge.
