# SEO 11 Global Semantic Core — Four Revenue Directions

Date: 2026-08-11  
Owner: SEO 11 revenue execution lane  
Scope: Google Search, Bing/Copilot, IndexNow participants, Yandex, AI/agent discovery  
Evidence status: business/offer validated; keyword-volume and ranking potential must be validated with authenticated search data before bulk expansion.

## Objective

Build one commercial search system for the four Hermes directions:

1. Logistics
2. Marketing / ProgressoPro
3. Academy
4. IT Development / Hermes Connect

The system optimizes for the measurable chain:

`query -> best canonical page -> useful answer -> CTA -> structured intake -> qualified inquiry -> sales follow-up -> outcome`

Search rankings are never guaranteed. Search Console achievements are traffic milestones, not ranking-system scores.

## Operating rules

1. One primary intent family has one preferred canonical owner.
2. Existing strong pages are expanded before new URLs are created.
3. New city, country, language, equipment, audience, or service pages require distinct intent plus unique useful content and a conversion path.
4. Supporting resources answer pre-sale questions and link to commercial owners.
5. Case studies prove implementation or approved outcomes; they do not compete with service pages.
6. Every indexable page must be canonical, internally linked, included in exactly one child sitemap, and tracked by page/query/country.
7. No thin city swaps, mass doorway pages, keyword stuffing, hidden text, fake reviews, fake locations, fake results, or unsupported availability claims.

# 8. Search-engine implementation

## Google

- Search Console property remains the source of truth for Google discovery/index/performance.
- Submit `sitemap-index.xml` plus retain child sitemaps for cluster diagnostics.
- Track each priority URL by index status, Google-selected canonical, query, page, country, device, impressions, clicks, CTR and position.
- Use URL Inspection selectively for high-priority new/changed money pages.
- Use Core Web Vitals field data when available; Lighthouse is lab evidence, not a ranking guarantee.
- Track Search Console Achievements as click milestones, not ranking scores.

## Bing / Copilot

- Connect the existing Bing Webmaster site rather than creating a duplicate property.
- Submit sitemap index and inspect child sitemap processing.
- Use IndexNow for new/updated/deleted canonical URLs.
- Track Search Performance, URL Inspection, Site Explorer, backlinks, crawl/index issues and IndexNow diagnostics.

## Yandex

- Add/verify the site in Yandex Webmaster when authenticated access is available.
- Submit the sitemap index.
- Use the existing IndexNow key/protocol for new/updated/deleted URLs.
- Prioritize Russian-language demand only where commercial/Academy intent is legitimate.

## Other IndexNow participants

The canonical IndexNow endpoint may distribute verified change notifications among participating search engines. Do not treat a successful notification as guaranteed indexing or ranking.

## AI / agent discovery

- Maintain a concise Markdown `llms.txt` with real crawlable links.
- Preserve crawlable HTML navigation, descriptive anchors, canonical pages and accessible forms.
- Add WebMCP annotations/tools only to useful public forms where an AI agent can safely complete the action without bypassing consent, qualification, security or business rules.
- AI Overviews / AI Mode eligibility still depends on normal Google index/snippet eligibility; there is no separate shortcut.

# 9. Page creation decision score

A new URL should score at least 7/10 before implementation.

- +2 authenticated impressions/query evidence
- +2 distinct commercial intent not satisfied by an existing owner
- +1 real differentiated service/audience need
- +1 unique operational knowledge/data
- +1 usable proof/resource/case support
- +1 clear CTA and qualification path
- +1 internal-link sources already exist
- +1 language/country localization adds real market value

Subtract:

- -3 thin location permutation
- -3 duplicates an existing canonical owner
- -2 unsupported claim/geography/capacity
- -2 no conversion path
- -2 no unique information
