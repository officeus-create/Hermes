# Logistics Data Locator Task

## Objective

Locate the exact one-year Hermes pickup/delivery and route-history database referenced by the owner and register it before the Logistics SEO pilot begins.

## Search locations

- connected Google Drive and shared drives;
- previously uploaded conversation/library files;
- Google Sheets used for load, shipment, carrier, shipper, lane, settlement, or dispatch history;
- local Hermes project folders only when the owner-approved agent has access.

## Search terms

- loads
- load history
- shipment history
- pickup delivery
- routes
- lanes
- dispatch
- carrier load database
- one year
- annual
- Hermes Logistics

## Required output

- exact file title;
- exact URL or file ID;
- source owner;
- tabs/files included;
- date range;
- row count;
- column names;
- privacy classification;
- fields usable for aggregated SEO analysis;
- fields that must never be published;
- access limitations;
- recommended normalization plan.

## Safety

Do not alter the source. Work read-only. Do not copy private shipment/customer/rate/contact data into GitHub. Store only metadata, aggregated findings, and a safe analysis plan.
