# Hermes Connect Repair Shops — First 10 Operating Scorecard

Use one row per real shop. The purpose is to learn where users stop and whether they pay, not to generate vanity traffic metrics.

## Shop-level fields

- shop identifier / CRM lead id
- source / referral owner
- city / state
- device used first: mobile / desktop
- language used
- owner registered: yes/no + date
- profile configured: yes/no + date
- first service created: yes/no + date
- availability configured: yes/no + date
- public booking link opened/shared: yes/no + date
- first booking received: yes/no + date
- first booking processed: yes/no + date
- customer record used: yes/no + date
- Founding Shop Plan viewed: yes/no + date
- paid activation requested: yes/no + date
- invoice sent: yes/no + date
- invoice paid: yes/no + date
- current paid/active state
- first-week usage notes
- strongest value reported
- biggest friction reported
- missing feature requested
- objection to $99 price, if any
- support question
- next action / owner / due date

## Funnel KPI

For every 10 shops calculate:

- registration rate
- setup completion rate
- first-booking rate
- plan-view rate
- paid-intent rate
- invoice rate
- paid conversion rate
- week-one active-use rate

## Decision rules

- If users do not register: fix acquisition message / trust / entry friction before adding features.
- If they register but do not configure: fix onboarding and defaults.
- If they configure but do not share the booking link: fix perceived value, setup completeness, or sharing UX.
- If customers open the link but do not book: fix booking UX, service information, trust, or availability.
- If shops use the product but do not view the plan: fix monetization placement.
- If they view the plan but do not request activation: record price/feature/trust objections before changing price.
- If they request activation but do not pay: fix sales follow-up, offer clarity, invoicing, or required commercial terms.
- Only add a new major Repair Shop feature when repeated real-user evidence points to the same missing capability.
