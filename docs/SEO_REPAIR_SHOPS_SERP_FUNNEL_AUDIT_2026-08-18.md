# Hermes SEO — Repair Shops SERP + Funnel Audit

Date: 2026-08-18  
Route: `/services/hermes-connect/repair-shops/`  
Status: `KEEP_CANONICAL_OWNER / STRONG_INTENT_FIT / VISUAL_FUNNEL_REVIEW_REQUIRED`

## Search intent observed

Current sampled `auto repair shop software`, `booking`, and `CRM` results are product-led landing pages. Repeated buyer expectations include:

- online booking;
- scheduling/calendar;
- customer/vehicle CRM or history;
- repair/job workflow;
- reminders/communications;
- operating visibility;
- a direct product action such as trial, demo, signup or get started.

The search archetype is not generic software development. It is vertical software built around the repair-shop workflow.

## Current Hermes owner fit

The existing Hermes page already has strong alignment:

- title: `Auto Repair Shop Software & Online Booking | Hermes Connect`;
- H1: `Give customers one link to book your repair shop.`;
- WebApplication schema identifies auto repair shop software;
- live capability copy covers booking, services, scheduling/availability, booking workflow, customers and vehicles;
- primary action goes to owner setup/registration;
- secondary action exposes the Founding Shop Plan;
- current product/status boundaries are explicit;
- browser-first use is explained;
- rankings/customer/revenue guarantees are explicitly rejected.

Decision: **do not create a second generic repair-shop-software owner.**

## Gaps that should NOT be filled by unsupported copy

Competitor pages often mention inventory, invoicing/payments, technician management, automated reminders, repair orders and other broad shop-management functions.

Hermes must not add those terms merely for keyword coverage unless the relevant capability is actually live and evidence-approved.

Current SEO advantage should remain focused on the truthful workflow that exists now.

## Funnel risk

The page begins as a clear Hermes Connect software acquisition page, but later introduces a substantial separate `Hermes Logistics repair partner` corporate-offer workflow with its own form and lifecycle.

This may create two competing buyer jobs on one canonical software page:

1. acquire/use Hermes Connect for the repair shop;
2. apply to be reviewed as a Hermes Logistics repair partner.

The second job is commercially legitimate but is not the primary search intent for `repair shop software / CRM / booking`.
