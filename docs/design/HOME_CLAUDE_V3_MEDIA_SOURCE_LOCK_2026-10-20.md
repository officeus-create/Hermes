**Correction (2026-10-22, Claude visual owner):** the previous draft of this PR re-encoded films **in place** under existing `/media/*` names. `/media/*` is served `immutable` for one year, so returning visitors would never have received new bytes. All previously shipped files are restored to their `main` bytes and left untouched; the new films use new `*-film-v2-*` names. `public/images/logistics-living/car-hauler-512.webp` is restored to its `main` bytes and provenance entry for the same reason.

**Conversion:** Source H.264 masters were center-cropped to the approved 9:16 windows and assembled using local FFmpeg/libx264 at 24 fps, `-an`, `-movflags +faststart`. All shots share one grade (`eq=contrast=1.04:saturation=1.06:gamma=0.98`) and are joined with 0.6 s crossfades. Runtime 540×960 files use CRF 25 (Logistics CRF 27); 720×1280 variants use CRF 26. Posters are regenerated from the matching local films. Source audio is discarded. No runtime Pexels fetch, subscription or paid-generation dependency remains. Every runtime file stays below the existing 1.5 MB Home media budget. Keep Pexels masters outside the production repository.

**Runtime policy:** The four native direction links remain real HTML. Every window now uses a local multi-shot film, attached only when allowed by the existing autonomous playback runtime; `Save-Data`, reduced-motion and no-JS keep the poster, and video pauses off-screen/in background. No fabricated stats, fake UI cards, duplicated tiny cars/books or business claims.
