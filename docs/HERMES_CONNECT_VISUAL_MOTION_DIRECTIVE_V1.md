# Hermes Connect — Visual Motion Directive V1

Status: APPROVED / LOCKED FOR WEB PRODUCT V1

## Owner feedback converted into implementation rules

The preferred visual reference is the richer animated preview direction, not a flat static dashboard.

### Must keep
- Pearl + Obsidian premium system with brighter Iris/Ocean/Sage accents.
- Compact Hermes interconnected-knot mark.
- Signature Hermes Flow / wave field.
- One unified Hermes Intelligence.

### Motion and depth
- The interface should visibly react to hover, pointer movement and module focus.
- Use layered parallax, gentle card tilt, hover lift, animated gradients, signal waves, orbiting particles and slow floating brand objects.
- The background should contain subtle motion even when the user is idle.
- Motion must remain calm/premium rather than game-like.
- Respect `prefers-reduced-motion` and provide a stable low-motion mode.

### Typography and readability
- Increase body copy, navigation labels and card copy from the current overly-small prototype scale.
- Maintain strong display typography, but use comfortable UI sizes for real work.
- Minimum target for normal desktop UI copy: ~14px where space allows; metadata may be smaller but must remain readable.

### Color
- Current product workspace feels too muted. Increase controlled accent contrast and use more visible Iris, Ocean, Sage and warm Pearl transitions.
- Different modules may have distinct accent energy while still using one Hermes system.
- Do not turn the product into a rainbow UI; accents are functional and directional.

### Brand object / Hermes launcher
- A floating Hermes knot / loop object should remain visible as a subtle living background/foreground object.
- The floating Hermes mark is also the primary launcher for Hermes Intelligence.
- Do not use Gemini, generic sparkle, robot-head, or third-party AI visual language as the primary Hermes Intelligence button.
- Hover/click on the floating Hermes object should open/focus Hermes Intelligence and may intensify the surrounding wave/orbit animation.

### Illustrative system
- Reintroduce the translucent 3D knot/loop sculpture, luminous waves, glass/orbital elements and premium abstract visual objects from the approved preview direction.
- Use them as interaction/progress/status storytelling, not decorative filler.

### Workspace implementation priority
1. Richer animated Home / Command Center.
2. Persistent floating Hermes Intelligence knot launcher.
3. Larger UI typography and stronger contrast.
4. Module-specific hover/parallax/microinteractions.
5. Animated background wave field.
6. Carry the same visual grammar into Inbox, CRM, Calendar, Sales, Marketing, Finance, Operations, Integrations and Academy.
7. Then harden Mobile Web with touch-safe alternatives to hover.

### Non-negotiable boundary
Visual richness must not imply fake live integrations or completed real-world actions. Demo/simulated states must be explicitly labeled until the corresponding backend connector is real and verified.
